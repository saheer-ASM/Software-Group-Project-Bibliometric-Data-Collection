## Scope and outcome

The validation tree contained **136 files** after this review when excluding `.venv`, bytecode/cache and the secret `config/config.env`; **79 Python files** were covered by the source/security search, with **75 runtime/entrypoint Python files** syntax-parsed and import-checked. All **11 RQs**, all **11 conventional baselines**, the stored NM target and six NM components were traced from design to input, module, statistic, output and report. The per-RQ trace is [rq_implementation_audit.csv](rq_implementation_audit.csv); the metric trace is [baseline_implementation_audit.md](baseline_implementation_audit.md). An existing module name or generated CSV filename was not counted as a complete implementation.

**Clear bugs found: 5. Fixed: 3. Unfixed: 2.**

1. **Fixed, critical:** `src/pipeline.py` previously set `full_portfolio_verified=True` for every author whenever the extracted snapshot had no internal link/quality blocker. Snapshot consistency is not proof of complete career coverage. It now defaults to false and accepts only a separate author-level `portfolio_verification` input with `author_id`, Boolean `portfolio_verified` and a nonempty `evidence_reference`. `src/external_inputs.py` admits and validates this local CSV kind. The mocked integration test proves the same synthetic author is excluded without attestation and eligible with one. This gate does not itself validate the external evidence; human/source verification remains necessary.
2. **Fixed:** Correlation heatmap generation previously replaced undefined correlations with `0`, visually asserting no correlation where data were absent. `src/pipeline.py` now passes NaNs through and `visualization/correlations.py` masks them in gray.
3. **Fixed:** RQ10's docstring said “component percentiles” while the implementation correctly uses six raw stored component scores. The misleading description was corrected; no PCA calculation changed.
4. **Unfixed:** `analysis/fairness.py` stores regional variance and two-group Cohen's d in `DataFrame.attrs`; `rq11_fairness.py` returns the frame and the CSV writer drops those attributes. The generic two-group order can reverse the design's **Male–Female** direction. Fix requires an approved label schema and effect/variance convention; until then, the exported `fairness_analysis.csv` cannot claim the requested effects.
5. **Unfixed:** `experiment_eligibility.csv` repeats common cohort counts for each RQ without checking each experiment's required inputs (award labels, longitudinal windows, demographic labels, etc.). It is not an experiment-specific eligibility report. Replace it with per-RQ input-completeness and exclusion accounting before an empirical run.

## Data, methods and statistical review

The directly defined default baselines—raw Total Cites, conventional h and conventional g—are separate from the NM weighted/modified components. The eight other baselines remain `METHODOLOGY_PENDING` and their default calculators reject calls without explicit strategies. Stored NM is read only from `author_nm_index`; no NM recalculation path exists. The written g rule is implemented with `g ≤ paper count`, but the latest manuscript's five-paper `g=12` example conflicts with that rule. An unreviewed programmatic strategy can currently be labelled `READY_WITH_EXPLICIT_STRATEGY` in provenance without proof of methodological approval, so external strategies are not cleared for data execution.

Statistical checks found correct pairwise finite-case handling and sample guards for the implemented Pearson/Fisher, paired t/Cohen d, ROC/AUC, prospective window, adjacent-year Spearman and PCA paths. Seeded stochastic paths include ICC bootstrap, AUC bootstrap and robustness sampling; stable-ID sorting is used for the sampled cohort. The current paired t implementation cannot interpret cross-metric raw-unit differences without an approved scale interpretation. RQ3 correctly defaults to `METHODOLOGY_PENDING` because the source does not specify an ICC form or score transformation. RQ4 produces AUC but not Table 4's awardee/non-awardee percentile means, Cohen's d, p-value or 13 award-category comparisons. RQ5 does not enforce its four distinct design cohorts and bins. RQ6 lacks the normalized paper-count trajectory. RQ7 computes local raw-citation changes but not the requested NM/h/C/hm/hf/g inflation table. RQ8 prevents use of contemporaneous outcomes by requiring a historical score-year snapshot and t+1…t+5 outcome dates, but does not verify the specified 10,000 complete longitudinal authors. RQ9 silently defines “>10% rank change” as more than 10% of paired cohort size; the source does not define that denominator or tie convention. RQ10 uses raw component scores, but PCA standardization/cohort choices need prespecification. RQ11 handles only NM and one supplied grouping variable, not both gender/region across the six requested indices. The CSV identifies missing effect sizes, CIs, figures and report outputs for every RQ.

The design gives explicit expected directions for RQ7, RQ10 and RQ11 but does not state separate formal hypotheses for all eleven RQs. The audit does not fabricate them. QQ, residual and Bland–Altman plots requested for RQ1, the combined ROC comparison for RQ4, and complete RQ5–RQ11 displays are missing or partial. The generated Markdown reports currently list files/statuses and coverage rather than numerical interpretations; they cannot serve as final research reports.

Data leakage search found no hard-coded author IDs or demonstration values in the runtime final dataset path. Synthetic authors and numerical fixtures occur in tests only. RQ7 simulations are local to gaming code and are not merged into `validation_dataset.csv`; supplementary robustness uses a seeded, sorted-ID sample. Inferred demographic labels are absent, but merely supplying a label CSV is currently treated as approval. Real label provenance must be checked independently. Output creation is restricted to the validation project's `results/` and `figures/` directories; per-run timestamped folders and non-overwriting CSV/PNG writers protect source documents and production files. `run_metadata.json` records timestamps, source hashes, package versions, seed, settings, sample/coverage counts and source kind without DB credentials. The existing generic reports do not adequately record each RQ's sample and exclusion rules.

## Blockers before any live data execution

1. **Cohort and provenance:** Verify full author–publication portfolios and complete coauthor/position coverage independently for each intended author; current linked data cover only 816 of 56,768 publications. Obtain a defensible 100,000-author stratified sample or explicitly approved smaller study scope. Apply the design's active-2000–2024 and metadata-completeness criteria, which the current global eligibility gate does not enforce.
2. **Citation semantics:** Approve the raw citation source and reconcile the large `publication.total_citation` versus `citation` edge discrepancies; do not silently treat one as the other. Verify complete author-level self-citation attribution and the stored NM missing-component policy.
3. **Baseline definitions:** Resolve raw/SC-adjusted C-score construction, conventional hm/hf, m career duration, Fi threshold, s-versus-b identity and AR formula; resolve the g example conflict. Review and attest each supplied strategy, its source, complete inputs and tests before any `READY` status.
4. **RQ-specific methods/inputs:** Approve ICC model/scale; verified award categories and percentile/p-value conventions; RQ5 scenario/cohort/covariate design; annual NM/C histories and normalized paper-count rule; local NM counterfactual method and fractional-count convention for RQ7; complete historical t/t+5 outcomes and longitudinal cohort; RQ9 rank-change denominator/tie/cohort rule; RQ10 PCA preprocessing/eligible cohort; approved gender/region labels and explicit effect-size direction/variance rule.
5. **Incomplete output contracts:** Implement the missing RQ4/RQ5/RQ6/RQ7/RQ11 table columns and comparisons, all required figures, experiment-specific eligibility/exclusion tracking and substantive result reports. Persist RQ11 effects in CSV rather than transient `DataFrame.attrs`.
6. **Reproducibility/governance:** Record independent portfolio evidence and approved citation/label/strategy provenance with the run; lock prespecified analysis settings, source data snapshot and exact inclusion/missingness policies. The current metadata is useful but not sufficient to reconstruct or audit a final study.
