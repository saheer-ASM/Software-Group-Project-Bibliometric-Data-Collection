# Phase 4.5 baseline data-source plan

This is an extraction plan, **not** an authorization to calculate metrics. The only populated stable-ID author–paper source is `author_contribution_weight` (816 papers); unpivot ten `authorNid` slots and deduplicate `(author_id,pub_id)`. The 55,952 remaining `publication` rows have no verified authorship. For raw paper counts, prefer `publication.total_citation` provisionally, with its provenance and disagreement with `citation` edges clearly labelled. Do not substitute NM-adjusted values for conventional raw citations. See [coverage](author_publication_coverage_investigation.md) and [citation audit](citation_semantics_audit.md).

The empty UUID `authors`/`publications`/`author_publications`/`citations`/`author_metrics` schema is not a fallback. The populated `citation` edge table is useful for diagnostics and NM-specific influence records, but its observed incoming edges cannot reproduce the stored citation totals for most papers. The plan requires independent provenance/completeness evidence before a final pilot cohort or comparative baseline computation.
