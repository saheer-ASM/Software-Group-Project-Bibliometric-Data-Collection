# Phase 4.5 pilot dataset readiness

Read-only audit date: 2026-10-04. This is an assessment; no pilot dataset or metrics were created.

1. **Can every publication be correctly associated with authors?** No. Only 816/56,768 papers have a populated stable-ID relationship; 55,952 have none in any candidate table inspected. The empty UUID junction offers no alternative. Five duplicate slot-pairs require deduplication, and ten slots cannot prove full coauthor coverage.
2. **Can every author be associated with publications?** No. 2,340/2,507 authors have observed links; 167 have none. An absent link is unknown portfolio coverage, not proof of zero publications.
3. **Can raw publication citation counts be obtained reliably?** A stored non-NULL value exists for every paper, but provenance/counting semantics are unverified. It differs from incoming edge counts for 48,165 papers; 48,056 positive-count papers have zero incoming edges. Use stored values only as explicitly labelled provisional source.
4. **Can self-citation information be obtained?** Only NM-specific influential-self-citation records for 90 cited papers/143 target authors. There is no complete conventional self-citation classification for the populated `citation` universe. The UUID `citations.is_self_citation` table is empty.
5. **Can contribution information be obtained?** Stored per-slot weights and order norms exist for 816 linked papers, but full authorship and interpretation for conventional hm/hf/C-score are unverified.
6. **Can publication years be obtained?** Yes for 56,760/56,768 papers; eight are NULL. That does not resolve missing portfolio or as-of conventions.
7. **Can NM-index values be obtained?** Yes: 2,321 non-NULL stored scores, 186 NULL rows; 784 scored rows have incomplete six-percentile coverage. `author_nm_index` is authoritative.
8. **Which metrics can be calculated safely?** None for an unqualified complete-career cohort **now**. The formulas for raw Total Cites and h are explicit and data can be read for the *observed linked subset*, but calling those complete-career metrics would be unsupported. g also needs its sample/domain conflict decided. Existing NM values can be read, not recalculated.
9. **Which metrics need methodology decisions?** hm, hf, g-example interpretation, m duration/as-of, s identity; C-score raw/SC-adjusted, Fi-score and AR-index need complete operational formulas and/or reference inputs. Citation-source definition and missing-data/cohort policy also need agreement.
10. **What minimum data-quality threshold should be used?** Proposed gate for any pilot comparison (not yet approved): **100% verified stable-ID author–paper links for every publication in each included author's defined portfolio; 100% non-NULL raw citation counts and publication years on those papers; 100% complete author-position/coauthor information for metrics needing it; no orphan or duplicate author–paper pair after explicit deduplication; an explicit citation-count provenance and snapshot; non-NULL authoritative NM score; and, for six-component analyses, six non-NULL stored component percentiles.** Report exclusions and coverage separately for each metric. This is a conservative proposed quality gate, not a claim that current data meets it. The experiment design also specifies at least five publications, at least ten citations, active record between 2000 and 2024, and complete publication years/positions for the final cohort; those eligibility rules cannot be applied reliably until portfolio completeness is established.

**Readiness:** The current database supports a labelled technical subset and audit work, but does not establish a defensible complete-career pilot cohort or all eleven baseline definitions. No final dataset should be assembled yet.
